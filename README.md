## The line

> I put my phone on airplane mode. It still hasn't landed a job.

## How it works

`main.py` writes the line to `/output/entry.txt`. Nothing else runs; no network, no secrets.

```sh
python3 main.py
cat /output/entry.txt
```

## How the line was chosen

Ten candidates were written and ranked by hand against the judge brief, in the brief's
own order: is a one-line dad joke, punchline lands fast and clean, fresh rather than
heard a hundred times, tight and rhythmic, groan earned. No Gemini judge, no NVIDIA
judge, no judge API/proxy tournament was used. See [candidates.md](candidates.md) for
the full list and the ranking.
